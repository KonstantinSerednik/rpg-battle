# Вариант A: Консервативный баланс

## Подход к балансу
**Философия:** Минимальные изменения, тонкая настройка существующих параметров. Цель — устранить очевидные дисбалансы (слишком сильные/слабые классы, неоптимальные атаки) без изменения ядра геймплея. Сохраняется текущая механика и темп боя.

## Изменения параметров персонажей

### Корректировка HP
Текущие значения HP приводят к разному времени выживания. Цель: привести HP к более сбалансированным значениям относительно урона.

### Ресурс (Энергия)
Текущая система: максимум 100 энергии, gain 10-40 за атаку, cost ульт 70-100. Проблема: некоторые ульты слишком дорогие относительно урона.

**Изменения:**
- Увеличить максимальную энергию до 120 для всех классов (позволяет накопить на ульту за 3-4 атаки вместо 4-5).
- Скорректировать energyGain для некоторых атак (см. ниже).
- Скорректировать energyCost ульт (см. ниже).

### Названия ресурсов
Оставить текущие названия (у всех "Энергия") для простоты.

## Баланс атак

### Общие принципы
1. **Урон базовых атак:** скорректировать значения, чтобы DPS (урон за использование) был сбалансирован между классами.
2. **Количество использований:** увеличить uses для слабых атак, уменьшить для сильных.
3. **Лечение:** баланс между уроном и лечением (отношение 1:1.2, т.к. лечение ценнее).
4. **Энергия:** gain должен соответствовать урону (примерно 1 энергия за 0.5 урона).

## Интеграция эффектов

### Подход
Используется **Вариант 2: Расширенный** (рекомендованный). Эффекты добавляются к определённым атакам для усиления их уникальности, но без кардинального изменения баланса.

### Добавление эффектов к атакам
1. **Воин - Рассечение:** добавляет эффект "Кровотечение" (dotDamage 3, duration 2).
2. **Маг - Ледяная стрела:** добавляет эффект "Замедление" (снижение energyGain на 20% на 1 ход).
3. **Лучник - Ядовитая стрела:** добавляет эффект "Отравление" (dotDamage 4, duration 3).
4. **Целитель - Благословение:** добавляет эффект "Бафф исцеления" (healingMultiplier 1.3 на 2 хода).
5. **Ассасин - Отравленный нож:** добавляет эффект "Слабость" (damageMultiplier 0.9 на 2 хода).
6. **Паладин - Молот праведника:** добавляет эффект "Освящение" (дополнительный урон 5 против нежити, но в игре нет типов, поэтому просто бафф защиты +5 damageReduction на 1 ход).
7. **Друид - Удар лозой:** добавляет эффект "Оковы" (снижение скорости атаки - уменьшение uses на 1 у следующей атаки).
8. **Алхимик - Кислотная бомба:** добавляет эффект "Разъедание" (damageReduction -3 на 2 хода).

### Влияние на баланс
Эффекты добавляют стратегическую глубину, но их мощность ограничена, чтобы не нарушить баланс. Эффекты с dotDamage компенсируются снижением прямого урона. Эффекты с модификаторами имеют короткую длительность.

## Метрики баланса

### Целевые показатели
1. **Средняя длительность боя:** 6-8 ходов (сейчас примерно 5-7). После изменений ожидается 6-8.
2. **Winrate классов:** стремиться к 45-55% для каждого класса в PvP (идеал 50%).
3. **Использование атак:** все атаки должны иметь частоту использования >10% (никакая атака не должна быть игнорируемой).
4. **Эффективность ультимейтов:** ульты должны составлять 20-30% от общего нанесённого урона.
5. **Разнообразие сборок:** каждый класс должен иметь как минимум 2 жизнеспособных набора атак.

### Текущее состояние (оценка)
- Воин и Паладин имеют преимущество из-за высокого HP.
- Маг и Ассасин слабы из-за низкого HP.
- Некоторые атаки никогда не выбираются (например, "Ловушка" лучника).

## Процесс балансировки

### Шаг 1: Анализ текущих данных
Собрать статистику из игры (если есть система сбора). Или провести ручное тестирование.

### Шаг 2: Внесение изменений
Реализовать изменения параметров в `src/db.ts`.

### Шаг 3: Тестирование
1. **Автоматизированные симуляции:** написать скрипт, который проводит 1000 боёв между случайными классами с случайными атаками (AI).
2. **Ручное тестирование:** сыграть 20-30 боёв в PvP режиме, фиксируя результаты.
3. **Анализ метрик:** рассчитать winrate, среднюю длительность, использование атак.

### Шаг 4: Корректировка
На основе результатов подстроить параметры (итеративно).

### Шаг 5: Внедрение эффектов
Добавить эффекты к атакам, проверить, не нарушают ли они баланс.

### Инструменты
- Excel/Google Sheets для расчётов.
- Простой Node.js скрипт для симуляций.
- Ручное тестирование с участием игроков.

## Ожидаемое влияние на геймплей
1. **Более длительные бои** из-за корректировки HP и урона.
2. **Больше стратегических решений** из-за эффектов.
3. **Улучшение баланса классов** — все классы будут более жизнеспособны.
4. **Увеличение разнообразия атак** — больше атак станут полезными.

## Сложность реализации
- **Низкая:** изменения только в `src/db.ts` (числовые значения).
- **Эффекты:** требуется реализация Варианта 2, что увеличивает сложность, но это отдельная задача.
- **Тестирование:** умеренные усилия на написание симуляций.

## Рекомендации по тестированию
1. **Симуляция 1000 боёв** между каждым классом (всего 28 комбинаций) для сбора статистики.
2. **A/B тестирование:** сравнить winrate до и после изменений.
3. **Фокус-группа:** привлечь 3-5 игроков для получения обратной связи.
4. **Мониторинг метрик:** после релиза отслеживать реальную статистику.

## Заключение
Консервативный баланс — безопасный путь, который улучшает игру без риска кардинальных изменений. Рекомендуется для быстрого исправления наиболее очевидных проблем перед внедрением более масштабных изменений.
