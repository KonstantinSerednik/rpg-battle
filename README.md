# RPG Arena – Пошаговая браузерная игра

RPG Arena – это интерактивная пошаговая игра в жанре фэнтези, где игроки выбирают персонажей, составляют набор атак и сражаются друг с другом или против искусственного интеллекта. Проект реализован на React с TypeScript и использует современный стек инструментов Vite.

## 🎮 Функциональность

- **Выбор режима**: PvP (игрок против игрока) или PvC (игрок против ИИ).
- **Выбор персонажа**: 8 уникальных классов с разными характеристиками здоровья и ресурса:
  - Воин 
  - Маг
  - Лучник
  - Целитель
  - Ассасин
  - Паладин
  - Друид
  - Алхимик
- **Выбор атак**: Каждый класс имеет 7 уникальных атак (4 обычных и 3 ультимейта). Игрок выбирает 4 атаки для своего персонажа перед боем.
- **Пошаговый бой**: Игроки по очереди используют атаки, которые наносят урон, исцеляют или дают/тратят ресурс.
- **Система ресурсов**: Обычные атаки генерируют ресурс, ультимейты тратят его.
- **Интеллектуальный ИИ**: В режиме PvC компьютер автоматически выбирает атаки и делает ходы.
- **Визуализация состояния**: Полоски HP и ресурса, подсветка активного игрока, лог действий.
- **Определение победителя**: Бой продолжается до обнуления HP одного из персонажей.

## 🛠 Технологии

- **React 19** – библиотека для построения пользовательского интерфейса.
- **TypeScript** – статическая типизация для надёжности кода.
- **Vite** – быстрый сборщик и dev-сервер.
- **CSS Modules** – стилизация компонентов (чистый CSS).
- **ESLint** – линтинг кода.
- **Lucide React** – иконки (если используются).
- **Recharts** – графики (зарезервировано для будущих расширений).

## 🧩 Ключевые компоненты кода

### `db.ts`
Содержит интерфейсы `Attack` и `CharacterPreset`, а также массивы `ALL_ATTACKS` и `PRESETS`. Здесь определены все классы, их здоровье, ресурс и список атак с параметрами урона, исцеления, затрат энергии и количества использований.

### `App.tsx`
Основная логика приложения:
- Управление состоянием игры (стадии, персонажи, ход).
- Обработка выбора персонажей и атак.
- Логика боя (расчёт урона, исцеления, затрат ресурса).
- ИИ для режима PvC.
- Рендер интерфейса в зависимости от стадии.

### Стили (`App.css`, `index.css`)
Тёмная тема с контрастными элементами, анимациями при наведении, полосками здоровья и ресурса.

## 🧠 Логика боя

- **Обычные атаки** наносят урон (положительное `damage`) или исцеляют (отрицательное `damage`), а также дают определённое количество ресурса (`energyGain`).
- **Ультимейты** наносят значительный урон/исцеление, но тратят ресурс (`energyCost`). Их можно использовать только при достаточном количестве ресурса.
- Каждая атака имеет ограниченное число использований (`uses`).
- Ресурс персонажа ограничен 100 единицами.
- Ход передаётся противнику после использования атаки, если цель не побеждена.

## 🧪 Тестирование

На данный момент проект не содержит автоматических тестов. Для ручного тестирования достаточно запустить приложение и проверить все сценарии:
- Выбор режима, персонажа, атак.
- Корректность подсчёта HP и ресурса.
- Работу ИИ в режиме PvC.
- Определение победителя.
