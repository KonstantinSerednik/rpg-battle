# RPG Arena – Пошаговая браузерная игра

RPG Arena – это интерактивная пошаговая игра в жанре фэнтези, где игроки выбирают персонажей, составляют набор действий и сражаются друг с другом или против искусственного интеллекта. Проект реализован на React с TypeScript и использует современный стек инструментов Vite.

**Ключевые особенности:**
- 8 уникальных классов с разными характеристиками и ресурсами
- Продвинутая система эффектов (баффы, дебаффы, щиты, контроль)
- Интеллектуальный ИИ с адаптивным поведением
- Конвейерная обработка ходов и статистики
- Полностью на русском языке интерфейса

## 🎮 Функциональность

### **Выбор режима**
- **PvP** (игрок против игрока) – два игрока по очереди выбирают персонажей
- **PvC** (игрок против ИИ) – игрок сражается против компьютерного противника с адаптивной логикой


### **Система эффектов**
Игра включает более 30 различных эффектов, разделённых на категории:
- **Дебаффы**: Кровотечение, Горение, Отравление, Уязвимость, Замедление
- **Баффы**: Сила, Защита, Регенерация, Берсерк
- **Щиты**: Магический щит, Божественный щит, Отражение
- **Контроль**: Оглушение, Заморозка
- **Специальные**: Воскрешение, Очищение, Медвежья форма

Эффекты имеют длительность, стаки, приоритеты и модификаторы характеристик. Они применяются автоматически через конвейер обработки хода.

### **Пошаговый бой**
- Игроки по очереди используют выбранные действия
- Каждое действие имеет ограниченное количество использований
- Ресурс ограничен 100 единицами, особые действия требуют затрат ресурса
- Эффекты автоматически обрабатываются в начале и конце хода
- Щиты поглощают урон перед здоровьем
- Оглушение пропускает ход

### **Интеллектуальный ИИ**
В режиме PvC компьютер использует адаптивную логику выбора действий:
- Оценивает доступные действия по урону, исцелению, эффектам
- Учитывает текущее здоровье, ресурс и состояние эффектов
- Приоритезирует защиту при низком HP
- Учитывает шансы применения эффектов
- Может использовать секретные действия при выполнении условий

### **Визуализация состояния**
- Полоски HP и ресурса с цветовой индикацией
- Иконки активных эффектов с таймерами
- Подсветка активного игрока
- Детальный лог действий на русском языке
- Статистика боя (история ходов, суммарный урон по действиям)

### **Определение победителя**
Бой продолжается до обнуления HP одного из персонажей. После победы показывается экран победителя с возможностью перезапуска игры.

## 🏗️ Архитектура проекта

### **Структура кода**
```
src/

├── context/GameContext.tsx    # Управление состоянием игры (React Context + Reducer)
├── effects/                   # Система эффектов
│   ├── effectLogic.ts         # Логика применения/удаления эффектов
│   ├── effectRegistry.ts      # Реестр обработчиков эффектов
│   ├── statPipeline.ts        # Конвейер расчёта урона/исцеления
│   └── turnPipeline.ts        # Конвейер обработки хода
├── ai/aiLogic.ts              # Логика искусственного интеллекта
├── components/                # React-компоненты
│   ├── ModeSelection.tsx      # Выбор режима
│   ├── CharacterSelection.tsx # Выбор персонажа
│   ├── AttackSelection.tsx    # Выбор действий
│   ├── BattleScene.tsx        # Экран боя
│   ├── WinnerScreen.tsx       # Экран победителя
│   ├── EffectIcons.tsx        # Отображение иконок эффектов
│   └── SelectionGrid.tsx      # Общий компонент сетки выбора
├── utils/                     # Вспомогательные утилиты
│   ├── logger.ts              # Логирование
│   ├── normalize.ts           # Нормализация числовых значений
│   └── secretAttack.ts        # Проверка условий секретных атак
└── App.tsx                    # Корневой компонент
```

### **Ключевые компоненты кода**

#### `db.ts`
Содержит интерфейсы `Attack` и `CharacterPreset`, а также массивы `ALL_ATTACKS` и `PRESETS`. Здесь определены все классы, их здоровье, ресурс и список действий с параметрами урона, исцеления, затрат энергии и накладываемых эффектов.

#### `src/types/game.ts`
Центральный файл типов, определяющий:
- `Effect` – структура эффекта с модификаторами, длительностью, стаками
- `Character` – расширенный персонаж с эффектами, щитами, состоянием оглушения
- `GameState` – полное состояние игры
- `Stage`, `GameMode`, `TurnRecord`, `AttackSummary`

#### `src/context/GameContext.tsx`
React Context + useReducer для управления состоянием игры. Обрабатывает:
- Выбор режима, персонажей, действий
- Логику боя через конвейер хода
- Применение/удаление эффектов
- Обновление лога и статистики

#### `src/effects/turnPipeline.ts`
Линеаризованный конвейер обработки хода:
1. Проверка оглушения
2. Расчёт затрат ресурса
3. Применение модификаторов эффектов
4. Расчёт урона/исцеления с учётом щитов
5. Наложение эффектов действия
6. Обработка эффектов начала/конца хода
7. Обновление статистики

#### `src/effects/effectLogic.ts`
Логика работы с эффектами:
- `applyEffect` – применение эффекта с учётом стаков и приоритетов
- `removeEffect` – удаление эффекта
- `cleanse` – очистка дебаффов
- `calculateModifiers` – расчёт суммарных модификаторов от всех эффектов

#### `src/ai/aiLogic.ts`
Интеллектуальный выбор атаки для ИИ:
- Оценка каждой доступной атаки по урону, исцелению, эффектам
- Учёт текущего состояния (HP, ресурс, эффекты)
- Приоритизация защиты при низком здоровье
- Поддержка секретных атак

## 🛠 Технологии

- **React 19** – библиотека для построения пользовательского интерфейса
- **TypeScript** – статическая типизация для надёжности кода
- **Vite** – быстрый сборщик и dev-сервер
- **CSS Modules** – стилизация компонентов (чистый CSS)
- **ESLint** – линтинг кода с strict правилами
- **Lucide React** – иконки для эффектов и интерфейса
- **Recharts** – зарезервировано для будущих расширений (графики статистики)

## 🧠 Логика боя


### **Система ресурсов**
- Каждый класс имеет уникальный ресурс
- Максимум 100 единиц ресурса
- Обычные атаки генерируют ресурс, ультимейты тратят
- Некоторые эффекты изменяют генерацию/трату ресурса

### **Эффекты и модификаторы**
Эффекты изменяют характеристики персонажа через модификаторы:
- `damageMultiplier` – множитель наносимого урона
- `damageReduction` – снижение получаемого урона
- `healingMultiplier` – множитель получаемого исцеления
- `energyGainMultiplier` – множитель генерации ресурса
- `criticalChance` – шанс критического удара
- `dodgeChance` – шанс уклонения

### **Щиты и оглушение**
- Щиты поглощают урон перед здоровьем
- Несколько щитов складываются
- Оглушение (`isStun: true`) заставляет пропустить следующий ход
- Очищение (`cleanse`) удаляет дебаффы
